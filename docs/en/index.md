# EMI Guardian documentation

EMI Guardian 0.0.2 is a KiCad 10.0.5+ IPC plugin that combines geometric EMI screening, ground-remediation planning, interactive board/fix/silkscreen previews, JLCPCB two-layer DFM checks, silkscreen cleanup, and convex-first board-outline optimization.
