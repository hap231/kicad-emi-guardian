# KiCad 10.0.5 実機受入試験

本手順は自動試験では確認できないKiCad GUI、公開IPC、OSインストーラー、実基板書き込みを確認します。必ず破棄可能な基板コピーを使用します。

## 1. 試験記録

次を記録します。

- OS名と版
- KiCad版
- KiCadが使用するPython版
- EMI Guardian版
- インストーラー名とSHA-256
- 試験基板のコミットまたはハッシュ
- 実施者、日時、合否、スクリーンショット

## 2. インストール、更新、削除

各OSで実施します。

1. KiCadを全終了します。
2. OS別Install-or-Updateを実行します。
3. `plugins/emi-guardian/plugin.json`を確認します。
4. KiCadを起動し、Plugin管理環境が作成されることを確認します。
5. 旧版から更新し、`plugins/emi-guardian`が1個だけ残ることを確認します。
6. KiCadの`plugins`直下に`_emi-guardian-backups`や`emi-guardian.installing-*`が残らないことを確認します。
7. インストーラーの実行中に、`plugins`配下とOS一時ディレクトリの両方を監視し、旧Pluginのコピーが一度も作成されないことを確認します。
8. 意図的な最終配置失敗では、不完全な配置だけが削除され、ロールバック用コピーが存在せず、原因修正後の再実行で導入できることを確認します。
9. Uninstallを実行し、本体と管理環境が消え、設定が保持されることを確認します。
10. 再インストールします。

WindowsではPowerShell実行ポリシー、macOSではGatekeeper／実行権限、Linuxでは実行ビットも確認します。

## 3. KiCad認識と起動

1. KiCad共通の設定 → PluginsでEnable KiCad APIをオンにします。
2. Python 3.9環境で起動試験します。
3. PCB Editorで基板を開きます。
4. ツール → 外部プラグインに`Open EMI Guardian`と`Quick EMI Scan`が出ることを確認します。
5. Open EMI Guardianを実行し、localhost画面が開くことを確認します。
6. 右下に未処理Pluginエラーがないことを確認します。

## 4. UIと言語

1. 基調色が青系であることを確認します。
2. 日本語へ切り替えます。
3. EMI指摘を1件以上発生させます。
4. 題名、説明、推奨対応、カテゴリ、測定項目名が日本語であることを確認します。
5. JLCPCB DFM指摘も詳細と推奨対応が日本語であることを確認します。
6. 英語へ戻し、同じ項目が英語になることを確認します。

## 5. 基板プレビュー

F.Cu、B.Cu、F.SilkS、B.SilkS、パッド、ビア、ゾーン、Edge.Cutsを含む基板を使います。

1. 解析後に配線、パッド、ビア、フットプリント、シルク、外形、指摘が表示されることを確認します。
2. 全体表示、拡大、縮小、ホイール／トラックパッド、ドラッグ移動を確認します。
3. 各レイヤーを個別にオン／オフします。
4. 全て／全て非表示を確認します。
5. 指摘マーカーをクリックして詳細が開くことを確認します。
6. 大規模基板では省略件数が表示され、ブラウザーが応答することを確認します。

## 6. KiCadで場所を表示

1. 配線に対応する指摘を開きます。
2. KiCadで場所を表示を押します。
3. 根拠配線がPCB Editorで選択されることを確認します。
4. 該当レイヤーが切り替わることを確認します。
5. 選択範囲へズームすることを確認します。
6. ズームアクションが使えない環境では、選択だけが成功しエラーで基板を変更しないことを確認します。
7. 解析後に対象アイテムを削除し、再度押して安全な「選択できない」表示になることを確認します。

永続的なDRCマーカーが作られないことは仕様です。

## 7. 折れ角判定

同一ネットで次のfixtureを作ります。

- 90°角
- 135°内角の一般的な45°配線
- 45°以下の鋭角
- 四角形パッドへ入る配線
- ビア上の折れ
- 3分岐
- 0.3 mm微小セグメント
- 円弧

確認:

1. 既定75°で90°と135°が指摘されない。
2. パッド、ビア、分岐、短区間、円弧内部点が除外される。
3. パッド除外範囲外の45°以下だけが指摘される。
4. 折れ角カテゴリが多数指摘でも不正に0.0点へ固定されない。
5. 閾値と除外設定を変更すると期待どおり変化する。

## 8. 長配線判定

1. 直線60 mm信号を作ります。
2. 合計長60 mmだが各端点経路が短い多分岐ネットを作ります。
3. 同じネットを複数の非接続成分にします。
4. 立上り時間、幾何閾値、`either`／`both`／`both_or_severe`を変えます。
5. 最大端点経路が表示され、全枝単純合計で誤判定しないことを確認します。
6. GNDと主要電源が既定除外されることを確認します。

## 9. 複数プリセットとJLCPCB

1. 低コストプロファイルを選びます。
2. 全11配線幅を複数選択します。
3. 両方のビアを選択します。
4. 設定保存と再読込後も選択一覧が保持されることを確認します。
5. 自動修正寸法が0.20 mm、0.60／0.30 mmになることを確認します。
6. 能力限界プロファイルで0.10 mm、0.25／0.15 mmになることを確認します。
7. 0.1 mm実配線と小径ビアを低コストDFMが警告することを確認します。
8. 板厚、色、シルク色、表面処理、発注bundleを確認します。

## 10. アンテナ修正プレビューと適用

次のfixtureを用意します。無害な突出部、GNDパッドのサーマル／逃げ経路、明示的GND配線、既存外周GND帯、真の未接続島、内部Edge.Cuts穴、凹外形です。

1. 全ての物理パッドとパッド保護余白が、アンテナ指摘およびルールエリアから除外されることを確認します。
2. 同一ネットのGNDパッド、ビア、明示的GND配線、既存外周GND成分が、指定幅`t`の保護バックボーンで広いGNDコアへ接続されたままであることを確認します。
3. 保護バックボーンの外側に残る余剰銅箔だけへ、形状一致ルールエリアが提案されることを確認します。
4. 提案部分をプレビュー上で除去しても、保護端子の接続や外周GND帯が失われないことを確認します。
5. 指摘生成後にパッドまたはGND経路を追加し、古い指摘からのルールエリアが再検証で拒否されることを確認します。
6. 決定的なアクションIDが同じ場合でも、ルールエリア形状または寸法が変化していれば適用直前の安全署名比較で拒否されることを確認します。
7. 基板を変更していない場合は、適用直前にアクティブ基板が再読込され、同じ選択案が完全一致で再生成されたときだけ1回適用されることを確認します。
8. 配線案の全幅、およびビア案の環状リング全体が、外側Edge.Cuts内、内部切り欠き外にあり、別ネットの配線、パッド、ビア、塗りつぶしベタを避けることを確認します。
9. 同一GNDベタ上だけを通る冗長配線が提案されないことを確認します。
10. 配線、ビア、配線＋ビア、ルールエリア候補を修正プレビューで確認します。
11. Dry-runで適用が遮断されることを確認します。
12. 基板コピーで選択項目を適用し、1つのUndo、同一ネット、ゾーン再塗りつぶし、KiCad DRCを確認します。
13. GNDとAGNDが接続されないことを確認します。

## 11. シルクプレビューと適用

1. F/B面、回転、ロック、狭い部品を含む基板を使います。
2. 0.8 × 0.8 mm、0.10 mmを確認します。
3. 現在シルクと提案値をオン／オフします。
4. パッド、ビア、基板端との衝突回避を確認します。
5. 安全な位置がない部品が見送りになることを確認します。
6. 適用後に参照非表示、値表示、正立、Undo、Gerberを確認します。

## 12. 外形最適化

1. 凸外形基板で既定8頂点案を作ります。
2. 元から凹部を1つ持つ基板で、その凹部だけが安全なら保持されることを確認します。
3. 元にない凹部が生成されないことを確認します。
4. 4、6、8、12、16頂点を指定し、目標値と実値を確認します。
5. 直交／斜め、0.1／0.5／1.0 mmグリッド、フィレットを確認します。
6. GND帯を証明できない場合に置換が遮断されることを確認します。
7. 基板名確認、バックアップ、Undo、DRC、Gerber、筐体干渉を確認します。

## 13. 長時間接続

1. 既定設定が無操作終了0、heartbeat 20秒、再試行2回であることを確認します。
2. 90分以上放置し、画面が意図的に終了しないことを確認します。
3. KiCadを一時終了して再起動し、基板を開き直した後の再接続動作を確認します。
4. OSスリープ／復帰を試験します。
5. 失敗時に画面が明確なエラーを表示し、基板を変更しないことを確認します。

## 14. 性能

小・中・大規模fixtureで解析時間とメモリを記録します。レポートのステージ時間を確認し、ラスタ刻み変更の速度と検出感度を比較します。大規模基板でUIが操作可能なことを確認します。

## 15. 最終製造確認

全変更後に、ゾーン再塗りつぶし、KiCad DRC、Gerber Viewer、ドリル、Edge.Cuts、マスク、シルク、3D／機構、JLCPCBアップロード後DFM、見積を確認します。必要なEMC／SI試験を別途実施します。

## 16. Findings操作とレイヤー制御

- [ ] 指摘マーカーのクリックで詳細が開く
- [ ] マーカーホバーで日本語要約が表示される
- [ ] Findings一覧ホバーで対応マーカーが強調される
- [ ] 「プレビュー上で場所を表示」で指摘へズームする
- [ ] レイヤー全解除後も指摘ポイントが残る

## 17. GND接続、アンテナ、ビアステッチング

- [ ] `*.Cu`スルーホールGNDパッドを含む連結ベタを未接続島と誤検出しない
- [ ] 物理パッドをアンテナとして指摘せず、ルールエリアがパッドへ重ならない
- [ ] パッド／サーマル逃げ、明示的GND配線、幅`t`接続路、既存外周GNDが保護される
- [ ] 保護バックボーン外の細長い余剰部だけに形状一致ルールエリアが優先表示される
- [ ] 古い指摘は現行基板に対して再検証され、安全証明できないルールエリアは出ない
- [ ] 適用直前にアクティブ基板を再解析し、消失または形状変更した選択案が1件でもあれば全適用を基板変更なしで中止する
- [ ] 基板未変更時は選択案が完全一致で再生成され、最終再検証後に1回だけ適用される
- [ ] 同一GNDベタ上だけの冗長な追加配線が提案されない
- [ ] 配線案の全幅が凹Edge.Cuts内に収まり、内部穴を横切らない
- [ ] 配線案とビア案が別ネットの塗りつぶしベタを避ける
- [ ] 配線案の表示幅が提案パラメータと一致する
- [ ] ステッチング候補が頂点付近を含み、過密・銅箔外・別ネット干渉を避ける
- [ ] 部分採用時に既存外周ビアの一括削除が無効になる

## 18. 外形回帰

- [ ] 添付例と同種の五角形で、提案面積が元面積を増やさない
- [ ] 最適化、現在形状の平滑化、現在形状のフィレットが別操作になる
- [ ] フィレット前ポリゴンの頂点が設定グリッドの倍数になる
- [ ] 外形プレビューに銅箔、シルク、パッド、ビア、部品が表示される

## 19. シルクと初期配置

- [ ] シルク線幅の既定値が0.10 mmである
- [ ] 0°、90°、±45°候補が使用される
- [ ] MountingHoleとLOGOの値が既定で非表示になる
- [ ] 参照番号がF.Fab／B.Fabへ移動し非表示になる
- [ ] 遠距離候補ではフットプリント上の要手動確認案になる
- [ ] 回路図シート単位で部品がグループ化され、ロック部品は動かない
- [ ] 同一ネットのコンデンサ候補が関連パッド付近へ提案される
- [ ] 各初期配置案に部品識別、移動先外形、移動後パッド、参照／値文字、移動ベクトルが表示される
