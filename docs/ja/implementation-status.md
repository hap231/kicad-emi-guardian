# 実装状況と要件対応表

バージョン0.0.2はKiCad 10.0.5以降向けの**公開前テスト版**です。形状・接続・設定に基づくエンジニアリングスクリーニングであり、EMI源の不存在証明ではありません。また、EMC適合や製造受理も証明しません。

| 要件 | v0.0.2の実装 | 残る制限・受入条件 |
|---|---|---|
| KiCadで場所表示 | UUIDを`KIID`へ変換し、根拠アイテムを選択、可能ならレイヤー切替と選択範囲ズーム | 永続DRCマーカーではない。ライブKiCadで要確認 |
| Findings操作 | マーカークリックで詳細、ホバーで要約、一覧ホバーでマーカー強調、プレビュー位置表示 | ブラウザーごとのポインター挙動を実機確認 |
| レイヤー操作 | 全選択／全解除。指摘ポイントは全解除でも保持 | 任意グラフィック全種を完全再現する3D表示ではない |
| 外形プレビュー | 現在基板の銅箔、シルク、パッド、ビア、部品、指摘へ提案を重畳 | 表示件数上限あり |
| 外形面積増加 | 面積増加拒否、既存外形保持、最適化／現在形状平滑化／フィレットを分離 | 機構条件は人が確認 |
| 外周ビア再構築 | 頂点優先、等間隔候補、同一GND銅箔内の全環状リング、クリアランス、部分採用時は旧ビアを削除しない | 既存ビア削除は明示選択と安全ゲートが必要 |
| アンテナ検出／修正 | 全パッド領域／逃げ余白、GNDパッド、ビア、明示配線、主GNDまでの必要幅`t`経路、既存外周GNDを保護。接続維持を証明した残差だけを指摘し、現在基板で正確なルールエリアを再検証。冗長配線と基板外新規銅箔を拒否 | 自動残差除去には閉じたEdge.Cutsと塗りつぶし形状が必要。励振・筐体・ケーブルを含む放射値は解かない |
| シルク | 0/90/±45°、線幅0.10 mm、MountingHole/LOGO非表示、距離上限、フットプリント上の要手動確認フォールバック、参照をFabへ移動し非表示 | ロゴ判定は名前・ライブラリ・説明のパターン依存 |
| 部分採用 | アンテナ、シルク、ステッチング、初期配置をチェックボックス選択し、選択状態をプレビュー表示 | Edge.Cuts置換は輪郭全体の一操作 |
| 2層リターン経路 | 一般的な層変更リターンビア警告を既定無効。欠損長／率、端点除外、主要電源除外、厳格化したGND迂回比／超過長、狭窄を評価 | 真の電流分布・周波数依存インピーダンスは近似 |
| GNDアイランド | ゾーン、配線、パッド、`*.Cu` THTパッド、ビアを同一ネット接続成分へ統合 | 未塗りつぶしゾーンは評価不能 |
| ビアステッチング | 頂点優先＋適度な間隔、過密回避、銅箔／クリアランス／最大数制限 | 全波長・筐体共振に対する最適密度ではない |
| Diagonal mode | `mode=diagonal`選択時に`allow_diagonal_edges`を同期 | 直交制約との同時指定は正規化される |
| ノイズチェック | スタブ、平行結合、鋭角、電気的長さ、基準面ギャップ、GND迂回・狭窄、端距離、差動長差、GND突起 | 「全ソフトより優秀」や無抜けを保証しない。対象回路のエッジ速度等を設定する |
| 回路ブロック初期配置 | 回路図シートパスでグループ化し、ロック部品保持、コネクタ外周寄せ、コンデンサを同一ネット候補パッド付近へ。移動先外形、パッド、文字、ブロック、識別ラベル、移動矢印をプレビュー | 回路意図を完全理解する自動配置器ではなくDry-run案 |
| 性能 | 空間索引、接続成分、探索上限、重複除去、プレビュー上限 | ラスタ処理は面積と解像度に比例 |
| 配布 | v0.0.2、3 OSインストーラー、日英文書、決定的ZIP、CI入力。旧Pluginのバックアップを作成せず、旧バックアップも自動削除 | 最終コピー失敗時はインストーラー再実行が必要。Windows/macOSのOS固有保護は各実機で確認 |

## 公開IPCの境界

基板スナップショット、選択、レイヤー、トランザクション、アイテム追加／更新、ゾーン再塗りつぶしを公開IPCの範囲で使用します。板厚、色、プロジェクトルールを`.kicad_pcb`の文字列置換で変更しません。

## 完了条件

自動試験、Python 3.9構文、JavaScript、POSIX shell、パッケージ構造、ZIP安全性、インストーラー隔離HOME試験、2回の再現ビルドを通した上で、ライブKiCad受入試験の未実施項目を明記します。
