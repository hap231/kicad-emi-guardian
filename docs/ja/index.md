# EMI Guardian ドキュメント

EMI Guardianは、KiCad 10.0.5以降を対象とし、形状ベースEMIスクリーニング、GND対策案、操作可能な基板／修正／シルクプレビュー、JLCPCB 2層DFM、シルク整理、凸形状を基本とする基板外形最適化を統合したIPC Pluginです。
