# 安全性、検証、制限事項

## 安全ゲート

- Dry-runは既定で有効で、全基板書き込みを遮断します。
- 適用にはUIの明示確認と最低確信度が必要です。
- 既存ネットは名前の完全一致で解決し、同名ネットを勝手に作りません。
- 自動銅箔対策とシルク変更は、利用可能ならKiCadトランザクションと単一Undoを要求します。
- ルールエリアは銅箔ベタだけを禁止するフラグを安全に設定できる場合だけ作ります。
- Edge.Cuts置換には、GND帯証明、保存済み基板、バックアップ、必要API、破壊的操作許可、基板名完全一致が必要です。
- JLCPCB低コストプロファイルでは、複数選択に微細寸法が含まれても自動修正へ工程限界寸法を誤採用しません。
- ローカルUIはループバックのみへbindし、ランダムトークン、CSP、要求サイズ制限、パストラバーサル対策を使用します。

## KiCad位置表示の安全性

「KiCadで場所を表示」は現在の選択を変更し、該当レイヤーとズームを試しますが、基板アイテムを作成・更新しません。カスタムDRCマーカーではありません。KiCadアクション名が利用できない場合はズームを省略し、安全側へ閉じます。

## 接続維持

無操作終了は既定0で無効です。20秒ごとのheartbeatと2回の再接続を行います。KiCad終了、基板閉鎖、OSスリープ、localhost遮断では一時切断します。再接続失敗時は書き込みを行いません。

## 変更後に必ず行う確認

1. ゾーンを再塗りつぶし、全銅箔レイヤーのサーマル、細首、島を目視します。
2. KiCad DRCを実行し、新規違反を確認します。
3. ビア径、穴径、環状リング、間隔、アスペクト比を製造条件と照合します。
4. 高速信号直下と層変更周辺のリファレンス面連続性を確認します。
5. コネクタ、意図したアンテナ、RFキープアウト、沿面、取付、筐体、面付け、治具を確認します。
6. Gerber Viewerでシルク、極性、1番ピン、マスク、外形を確認します。
7. Edge.Cutsの閉路、寸法、切欠き、タブ、スロット、取付穴、レールを確認します。
8. EMC重要製品では測定または検証済みソルバを使用します。

## 主な制限

- 「全アンテナ候補」は、取得できた塗りつぶしゾーンを設定ラスタ解像度で全走査した範囲です。物理放射源の不存在証明ではありません。
- 静的形状だけでは、電流、位相、励振、終端、ケーブル、筐体共振、コモンモード変換、規格限度を決定できません。
- ゾーン外形フォールバックは銅箔を過大評価する場合があります。評価前に塗りつぶしてください。
- 円弧は解析用の弦へ分解されますが、同一円弧内部点は鋭角判定から除外します。
- パッド形状は近傍除外と衝突判定で外接矩形へ保守的に簡略化します。
- 長配線は最長端点経路の近似であり、真のドライバー／レシーバーを推論しません。
- プレビューは簡略SVGで、3D電磁界・製造結果ではありません。大規模基板では表示件数上限があります。
- 外部ソルバ出力は未解析モデルで、ポート、励振、境界、メッシュ収束を自動確定しません。
- 自動外形は筐体、パネル、治具、アンテナ意図を理解しません。
- JLCPCBの公開能力と価格条件は変更されます。
- 自動試験環境にはライブKiCad GUI、実機EMC、製造受入がないため、[実機受入試験](acceptance-test.md)が必要です。
