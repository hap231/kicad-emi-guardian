# 操作手順

## 1. 起動

PCB Editorで対象基板を開き、**ツール → 外部プラグイン → Open EMI Guardian**を選びます。初回はDry-runを維持します。

## 2. JLCPCB設定

1. JLCPCB製造を開きます。
2. 通常は2層・低コストを選択します。
3. 板厚、レジスト色、銅厚、表面処理、分割方法を選びます。
4. 配線幅とビアを1つ以上ずつ選択します。複数選択できます。
5. プロファイルを適用し、DFMチェックを実行します。

複数選択はルーティングカタログです。自動修正寸法は有効プロファイルを満たす安全な既定値になります。

## 3. 解析

**解析を実行**すると、現在の基板を再取得し、GNDアンテナ、平行配線、鋭角、長配線、リターン経路、基板端、差動対、DFMを評価します。

日本語UIでは指摘の題名、説明、推奨対応、測定項目も日本語です。指摘をクリックして詳細を開きます。

## 4. 基板プレビュー

- 全体表示、拡大、縮小
- ホイール／トラックパッド拡大
- ドラッグ移動
- `F.Cu`、`B.Cu`、`F.SilkS`、`B.SilkS`、パッド、ビア、フットプリント、指摘の表示切替

指摘マーカーをクリックすると詳細を開きます。

## 5. KiCadで場所を確認

**KiCadで場所を表示**を押すと、根拠アイテムを選択し、可能なら該当レイヤーへ切り替えて選択範囲へズームします。永続DRCマーカーではありません。ズームに失敗しても選択できている場合は、KiCadの手動ズームを使用します。

## 6. 折れ角と長配線

既定の鋭角閾値は75°です。90°は指摘しません。パッド、ビア、分岐、短セグメント、円弧近似点は除外します。

長配線は全枝合計ではなく、ネット接続成分の最長端点経路を使用します。実際の立上り時間を設定してください。

## 7. アンテナ修正

1. アンテナ修正画面で案を作成します。
2. 修正プレビューで配線、ビア、ルールエリアを確認します。
3. レイヤーを切り替え、拡大して干渉を確認します。
4. Dry-run解除と明示確認後に適用します。
5. ゾーン再塗りつぶしとDRCを実行します。

## 8. シルク整備

1. シルク配置案を作成します。
2. 現在のシルクと提案値をプレビューで比較します。
3. 配置できない部品、極性、1番ピン、認証表示を確認します。
4. 必要な寸法を設定し、Dry-run解除後に適用します。
5. Gerberで確認します。

## 9. 外形最適化

既定は斜め辺あり、凸形状基調、目標8頂点です。元外形の凹部だけ、安全なら保持します。目標頂点数、グリッド、フィレット、余白、GND帯を設定し、提案を確認します。

自動置換はGND帯、面積削減、安全条件を満たし、破壊的置換を明示的に許可した場合だけ可能です。

## 10. 接続と長時間利用

既定は無操作終了なし、20秒ハートビート、2回再接続です。KiCadを閉じた場合やOSスリープ後は、基板を開き直して再解析します。

## 11. レポート

HTML、JSON、MarkdownとJLCPCB bundleを出力できます。処理時間、日英表現、根拠アイテム、設定仮定を含みます。

詳細は[取扱説明書](user-manual.md)を参照してください。
